# Forgotten Composers: British Orchestral Music 1850–1950

A static GitHub Pages edition of the Forgotten Composers Blogger site, copied on 20 October 2026. The original Blogger site remains available at https://forgottencomposers1850-1950.blogspot.com/.

## Publishing

In repository Settings → Pages, select **Deploy from a branch**, **main**, and **/(root)**.

Expected site address: https://martinrobertwalsh.github.io/British-Composers/

## Updating

Edit the HTML pages and shared assets directly. Blogger changes do not automatically sync to this copy. The existing Macfarren audio folder is preserved.

The site includes Home, A–Z List, In the Pipeline, and both published articles. Images and backgrounds are stored under `assets/` for caching. Welcome and Archive dialogs and the A–Z portrait carousel work locally. Blogger comments, Blogger administration, and Blogger search are not copied into the static site.
