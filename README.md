# Forgotten Composers: British Orchestral Music 1850–1950

A static GitHub Pages edition of the Forgotten Composers Blogger site, synchronized on 22 October 2026. The original Blogger site remains available at https://forgottencomposers1850-1950.blogspot.com/.

## Publishing

In repository Settings → Pages, select **Deploy from a branch**, **main**, and **/(root)**.

Expected site address: https://martinrobertwalsh.github.io/forgotten-british-composers-1850-1950/

## Updating

Edit the HTML pages and shared assets directly. Blogger changes do not automatically sync to this copy. The existing Macfarren audio folder is preserved.

The site includes Home, A–Z List, In the Pipeline, and four published articles: Walter Macfarren, Percy Godfrey, Arthur Hervey, and Sliding into the shadows. The A–Z page includes the revised upper list and a complete birth-order list with UK copyright markers. Shared styles and backgrounds are stored under `assets/`; article images also use their original Blogger image URLs. Welcome and Archive dialogs, sharing controls, and the A–Z portrait carousel work locally. Audio players pause other media when playback starts. Blogger comments, Blogger administration, and Blogger search are not copied into the static site.
